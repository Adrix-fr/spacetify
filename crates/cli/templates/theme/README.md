# {{name}}

A spacetify theme.

## Try it

```sh
spacetify dev .
```

Spotify starts with this theme. Each time you save a file, spacetify checks
it and reloads Spotify's interface, without restarting Spotify. Close
Spotify to stop.

## Files

- `theme.toml`: the name, version… of the theme.
- `colors.toml`: Spotify's colours, replaced.
- `theme.css`: anything else.

## Share it

`spacetify gallery pack .` checks the theme and prepares it for the
gallery's request form (or use the *Submit* page of the spacetify app).
